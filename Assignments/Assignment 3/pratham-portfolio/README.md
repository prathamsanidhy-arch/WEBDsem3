# Pratham Agarwal - Developer Portfolio

A cinematic, monochrome, high-performance personal developer portfolio built with Node.js, Express, HTML, CSS, and Vanilla JavaScript.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the server:
   ```bash
   npm start
   ```

3. Visit `http://localhost:3000`

## Assets

Ensure the following assets are placed in the `public/assets/` directory:
- `hero.mp4`: The main cinematic laptop hero video.
- `pratham-logo.png`: The chess-inspired custom logo.
